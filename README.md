# Эпохи

Автономная нарративная стратегия о развитии цивилизации. За 12 решений игрок проводит народ через четыре эпохи, балансируя запасы, знание, культуру, порядок и население.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. Сборка: `npm run build`, тесты: `npm test`. В проекте нет обязательных внешних зависимостей.

## Принятые решения

- Первая версия сделана как компактная браузерная игра без сервера: её легко запускать и размещать как статический сайт.
- Старый проект трактуется как источник общего видения; модель событий, состояние и интерфейс спроектированы заново.
- Один забег намеренно занимает 10–15 минут. Прогресс автоматически хранится в `localStorage`.
- Тексты, система пяти ресурсов, 12 событий, четыре финала и визуальный язык входят в репозиторий и не требуют внешнего API.

## Известные ограничения

- В первой миссии одна фиксированная цепочка событий; вариативность создают решения и четыре типа финала.
- Нет облачной синхронизации, локализации и звукового оформления.
