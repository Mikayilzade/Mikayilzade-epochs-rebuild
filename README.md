# Эпохи

«Эпохи» — автономная пошаговая стратегия на карте. Игрок проводит народ через четыре исторические эпохи: исследует связанные области, собирает армии, строит поселения, архивы и крепости, выдерживает экспансию двух соперников и формирует наследие державы.

## Быстрый запуск

Требуется Node.js 20 или новее. Внешние пакеты не нужны.

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Другой порт можно назначить через `PORT=8080 npm start`.

## Управление

1. Выберите принадлежащую вам область на карте.
2. Потратьте два доступных действия на набор армии, строительство или поход в соседнюю область.
3. Завершите ход: владения принесут пищу и знания, после чего походы выполнят соперники.
4. К концу 16-го хода удерживайте не менее семи областей и накопите 12 единиц наследия.

После накопления 20 знаний цивилизация получает третье действие на ход. Пища оплачивает строительство и войска, архивы ускоряют исследования, крепости дают защиту, а поселения поддерживают экспансию. Игра автоматически сохраняется в браузере.

## Команды

```bash
npm test       # тесты правил и полного цикла кампании
npm run build  # автономная статическая сборка в dist/
npm start      # локальный HTTP-сервер
```

## Архитектура

- `src/game.js` — детерминированная модель карты и чистые операции над состоянием.
- `src/main.js` — представление, управление и локальное сохранение.
- `src/style.css` — адаптивная карта и визуальная система без внешних ресурсов.
- `test/game.test.js` — проверки экономики, приказов, противников и завершения кампании.

## Ограничения первой миссии

- ИИ соперников намеренно прозрачен: он атакует самое слабое соседнее владение.
- Кампания рассчитана на одиночную игру на одной авторской карте.
- Звук, локализация и облачное сохранение не входят в автономный вертикальный срез.
